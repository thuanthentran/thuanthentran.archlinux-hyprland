# archlinux_hyprland

Cấu hình Arch Linux + Hyprland cá nhân. Mục tiêu là cài lại Arch trên máy cũ hoặc máy khác, clone repo này, chạy vài lệnh là có lại đúng môi trường.

## Trạng thái

Đang ở giai đoạn chuẩn bị (2026-11-15). Repo mới chỉ có tài liệu, chưa có config hay script nào, và Arch chưa được cài trên máy.
